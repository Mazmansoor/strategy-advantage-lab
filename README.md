# The Strategy Advantage Lab

**Think Better. Decide Wiser. Act Together.**

An interactive strategic-judgment experience for individuals, leadership teams, and facilitated workshops.

## Run locally
Open `index.html` in a modern browser. It is a standalone static prototype.

## Deployment
Production: https://strategy-advantage-lab.vercel.app

**GitHub → Vercel auto-deployment is not yet connected.** In the existing Vercel project `strategy-advantage-lab` (Studio33), open **Settings → Git** and connect this repository (`Mazmansoor/strategy-advantage-lab`) with `main` as the production branch. Do not create a duplicate Vercel project. After connecting, confirm a new commit triggers deployment and the original URL stays online.

## Project content
Book, branding and workshop materials: https://drive.google.com/drive/folders/1zYEyFfWuPsFKJddhWG3vI0m1zBy53tCp

## Product status
Currently a prototype: no real AI backend, multiplayer, payment processing or user accounts. Keep API keys and private participant data off static pages.
